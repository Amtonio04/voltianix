## 🚀 Instalación Rápida

### Requisitos Previos
- Node.js v16+
- npm o yarn
- Git

### Pasos

1. **Clonar el repositorio**
```bash
git clone https://github.com/Amtonio04/voltianix.git
cd voltianix
```

2. **Instalar dependencias**
```bash
npm install
```

3. **Configurar variables de entorno**
```bash
cp .env.example .env.local
```

4. **Iniciar en desarrollo**
```bash
npm run dev
```
